## Sobre

Especialista de Dados com **10+ anos** transformando grandes volumes de dados em decisão. Atuo em **Prevenção a Fraudes na Saúde Suplementar**: detecção de padrões anômalos, indicadores de risco, regras de negócio complexas e dados sensíveis tratados com rigor (LGPD).
